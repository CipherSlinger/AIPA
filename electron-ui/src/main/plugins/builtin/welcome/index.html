💡 插件开发极简指引 (Developer Guide)
只需 3 步，打造专属于你的桌面 AI 扩展工具：
1
创建文件夹与清单配置
在 ~/.aipa/plugins/ 下新建一个文件夹（如 my-tool），创建 plugin.json，定义插件名称（name / nameEn）与图标（如 Terminal、NotebookPen、Blocks），插件会出现在左侧栏上方区域。
2
编写原生网页界面
在同目录下创建 index.html，使用原生 HTML5、CSS3 和 JavaScript 编写任何你想要的界面或小工具。无需 Node.js、Vite 或 Webpack 打包，任意文本编辑器修改保存后即刻热生效。
3
与 AIPA 核心驾驶舱双向通信
插件运行在安全独立的沙箱环境中，可直接调用 window.parent.postMessage：
• { type: 'aipa:sendPrompt', payload: { prompt: '...' } } —— 自动填入主对话框并唤起 AI；
• { type: 'aipa:toast', payload: { type: 'success', message: '...' } } —— 触发桌面轻提示；
• { type: 'aipa:storage:set', payload: { key, value } } —— 跨会话持久化存储插件数据。

💡 Developer Guide
Three steps to your own desktop AI tool:
1
Create a folder and manifest
Make a folder under ~/.aipa/plugins/ (e.g. my-tool) and add a plugin.json with the name (name / nameEn) and a Lucide icon such as Terminal, NotebookPen or Blocks. Plugins appear in the upper section of the left rail.
2
Write a plain web page
Add an index.html in the same folder and build any UI with HTML5, CSS3 and JavaScript. No Node.js, Vite or Webpack needed — edit in any text editor and changes apply on save. The page URL carries ?lang=en or ?lang=zh-CN so you can follow AIPA's language.
3
Talk to AIPA
Plugins run in an isolated sandbox and call window.parent.postMessage:
• { type: 'aipa:sendPrompt', payload: { prompt: '...' } } — fill the main chat input and bring up the AI;
• { type: 'aipa:toast', payload: { type: 'success', message: '...' } } — show a desktop toast;
• { type: 'aipa:storage:set', payload: { key, value } } — persist plugin data across sessions.
